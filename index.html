How it works

From download to https in minutes.

No config files to edit and no services to install. Everything lives in one folder.

Install

Run the installer, then click Install components. DevHearth downloads the official Apache, Nginx, PHP and MySQL builds once.

Approve two prompts

Trust the local certificate so HTTPS works, and allow one hosts-file update so .test domains resolve.

Add a folder

Create or clone a project in C:\DevHearth\www. It's served right away at its own https address.

FAQ

Questions

Is DevHearth free?

Yes. It's free for personal and commercial work. It isn't open source; see the license.

Why does Windows say "Windows protected your PC"?

DevHearth is new and its installer isn't code-signed yet, so Windows SmartScreen warns about it. Click More info, then Run anyway. The installer only writes to C:\DevHearth and doesn't need admin rights.

What does it change on my computer?

With your approval, it adds a local certificate authority to your user's trusted certificates (so https://*.test works) and adds your project domains to the Windows hosts file. Its private key never leaves your computer. There's no telemetry.

Can I use it alongside XAMPP or Laragon?

Yes, but not at the same time on the same ports. Stop the other stack first, or change DevHearth's ports in Settings.

Does it work on macOS or Linux?

Not yet. DevHearth is Windows-only today; macOS and Linux versions are planned.

How do I uninstall it?

Use Windows Settings ▸ Apps ▸ DevHearth. Servers, configs and logs are removed; your www projects and data databases are kept.
